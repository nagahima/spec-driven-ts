# /grill-me

計画や設計についてユーザーを徹底的にインタビューし、すべての判断分岐を解消して共通理解に到達します。

## 発動条件

- ユーザーが「grill me」「グリルして」「質問して」「詰めて」と明示的に依頼したとき
- 仕様・設計のストレステストやレビューを求められたとき

## 手順

1. ユーザーが提示した計画・設計・アイデアを把握する
2. コードベースを探索し、文脈から答えられる問いは自己解決する
3. **1回につき1問だけ**質問する（複数まとめて聞かない）
4. 各質問には推奨される回答例を添える
5. 回答を受けて次の問いを決定し、判断ツリーを系統的に掘り下げる
6. 相互に十分な明確さが得られるまで繰り返す

## ルール

- 質問は必ず1問ずつ、推奨回答とセットで提示すること
- ユーザーが「stop」「終了」「enough」と言うまで継続すること
- 質問が尽きたと感じても、想定外のリスクや副作用の観点から追加質問すること
- このリポジトリのコンテキスト（`specs/features/`、`packages/types/` など）を積極的に参照すること
