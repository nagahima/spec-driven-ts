# /doc-sync

仕様からドキュメントを生成・更新します。

## 手順

1. `specs/features/*.md` を全て読む（`_TEMPLATE.md` は除外）
2. 機能ドキュメントの生成：
   - ステータスが `implemented` の仕様を対象に `docs/features/[name].md` を生成
   - 内容: 機能の概要・使い方（コマンド例）・受け入れ条件の要約
3. 既存の横断ドキュメントを最新化：
   - `docs/user-stories.md` — 実装済みコマンドとユーザーストーリーの一覧。
     新しいコマンドや機能が増えていれば追記し、「現在の制限事項」を実態に合わせて更新
   - `docs/sequence-diagrams.md` — 主要フローのMermaidシーケンス図。
     フローが変わっていれば該当図を更新
4. `docs/README.md` にすべてのドキュメントの索引を生成・更新
5. 更新したファイルの一覧と変更点の要約を報告
