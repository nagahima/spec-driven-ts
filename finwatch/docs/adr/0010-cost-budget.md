# ADR-0010: コスト制御 — 月$25のトークン予算と実行回数設計

Status: Accepted / Date: 2026-07-02

## Context
個人運用の予算上限は月$20-25。コスト源はAnthropic API(主)とEDINET DBレート枠(Free 100req/日)。

## Decision
1. モデルはSonnet系を既定とし、レポート整形などの機械的処理はHaiku系に振り分ける(モデルルーティングは設定値)
2. 1回のレポート生成のトークン予算を設定(`config/budget.json`: input 200k / output 8k 目安)。超過時は処理を打ち切り、部分レポート+超過警告を出す(fail-visible)
3. eval実行はトリガー限定(ADR-0009)。月次コストをレポートフッターに自己申告表示
4. MCP呼び出しはキャッシュ(ADR-0007)で削減。有報全文(get_text_blocks)は必要セクションのみ取得

## Alternatives
- **常時最上位モデル**: 品質は上がるが予算超過。品質差はevalで測ってから判断する(推測で盛らない)

## Consequences
- (+) コストが設計パラメータとして可視化され、面接でも「コストをNFRとして扱った」と語れる
- (-) 予算打ち切りによる部分レポートが発生しうる → SLOの品質定義に「完全性」を含めて監視
