# ADR-0008: 外部ツールスキーマの変動防御 — スナップショット + 契約テスト

Status: Accepted / Date: 2026-07-02

## Context
EDINET DBのツール群は活発に増減している(公開後数ヶ月で7→17→37ツール)。外部スキーマの破壊的変更は、静かな実行時故障(引数不一致、レスポンス構造変化)として現れる。

## Decision
1. `tools/list` の結果を `contracts/edinetdb.snapshot.json` としてコミット
2. CI(日次スケジュール)で本物のサーバーに `tools/list` を実行し、スナップショットとdiff。**利用中ツール(allowlist)に破壊的変更があればCIを赤にする**。未使用ツールの増減は通知のみ
3. レスポンスはzodスキーマ(`src/mcp/schemas/`)でパースし、パース失敗は「外部契約違反」として通常のエラーと区別したメトリクスで記録
4. モックMCPサーバー(`tests/contract/mock-server.ts`)はスナップショットから自動生成し、テストと現実の乖離を防ぐ

## Alternatives
- **実サーバーに対するE2Eのみ**: レート枠を浪費し、CI が外部可用性に依存して不安定化。契約テスト(モック)を主、実サーバー検証は日次1回に限定

## Consequences
- (+) 「動いていたものが黙って壊れる」を検知時点で捕捉。メンテナンス作業がdiff駆動になる
- (-) スナップショット更新の運用が増える → 更新PRを自動生成するワークフローで軽減
